\# Tienda online


\## Descripción

Tienda online de productos varios. Permite a los usuarios ver productos desde una API, agregarlos al carrito y simular una compra.



\## Estructura del proyecto

\- `index.html`: Página principal con productos

\- `paginas/carrito.html`: Página del carrito de compras

\- `paginas/contacto.html`: Formulario de contacto

\- `css/styles.css`: Estilos responsive

\- `js/`: Archivos JavaScript organizados por funcionalidad



\## Tecnologías utilizadas

\- HTML5 semántico

\- CSS3 con Flexbox y Media Queries

\- JavaScript vanilla

\- Fetch API

\- LocalStorage
